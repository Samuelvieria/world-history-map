# MEDIDO: `pip install -r requirements.txt` sozinho traz o torch CPU-only do
# PyPI (`2.13.0+cpu`), mesmo numa maquina com GPU NVIDIA — nao e' automatico.
# Sem CUDA, ingestao de PDF real mediu ~41s/pagina (livro de 270 paginas ~= 3h
# de CPU). Se tiver GPU NVIDIA, troque o torch DEPOIS de instalar este
# arquivo:
#   ./.venv/Scripts/pip install torch==2.13.0+cu126 --index-url https://download.pytorch.org/whl/cu126
# (cu126 e' compativel com qualquer driver que suporte CUDA >= 12.6 — o
# runtime do wheel roda sobre driver mais novo sem problema. Ver driver com
# `nvidia-smi`.) Alem disso, `GLiNER.from_pretrained` tem `map_location='cpu'`
# como padrao mesmo com CUDA disponivel — `extracao/extrator.py` detecta e
# passa `map_location='cuda'` quando aplicavel; sem esse ajuste no codigo, a
# GPU fica instalada e sem uso.
#
# MEDIDO numa RTX 3060 (8GB, driver WDDM): carregar o modelo na GPU custa
# ~180s (contra poucos segundos na CPU) — mas isso e' UMA VEZ por processo.
# Depois disso, processamento real caiu de ~8s/pagina (CPU, 4 chamadas
# predict_entities por pagina) para ~0,45s/pagina — ~18x mais rapido no
# regime permanente. Um livro de 270 paginas: ~3h em CPU vira ~5 min em GPU
# (180s de carga + 264 paginas uteis x 0,45s).
